# 00 Start

This is the starting point for the City Explorer workshop.

At this checkpoint:

- The project structure is ready.
- Leaflet is loaded.
- Esri Leaflet is loaded.
- Esri Leaflet Vector is loaded.
- ArcGIS configuration is available.
- Prepared city datasets are included.
- The map container is ready.
- No Leaflet map has been initialized yet.

You're ready to build the map.
